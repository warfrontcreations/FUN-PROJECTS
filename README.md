# FUN PROJECTS

A collection of small personal projects.

## Projects

- **[whatsapp-assistant](./whatsapp-assistant)** — a personal WhatsApp
  auto-reply bot that generates replies in your own texting style using
  Claude.
- **[screen-shield](./screen-shield)** — a native Windows overlay that hides
  a region of your screen from screenshots and screen recordings.

Each project has its own README with setup instructions.
